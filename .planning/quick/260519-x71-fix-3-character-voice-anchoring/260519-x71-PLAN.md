<objective>
Add character-voice anchoring to per-turn prompts so the 13 core characters sound stylistically distinct. Pure prompt-assembly change: three new optional fields on the Friend type (`mesExample[]`, `antiPatterns[]`, `stances{}`), a helper that emits 0–3 lines from them, and injection at two U-shape positions (top + end of prompt).

Purpose: OpenCharacter (arxiv 2501.15427) shows writing samples outperform descriptions. SillyTavern `mes_example` and Character.AI persona cards use the same pattern. Today every character routes through the same generic prompt skeleton — distinct systemPrompts get diluted by the surrounding instruction block.

Output:
- Type additions on Friend
- Helper `buildVoiceAnchorBlock(friend, userMessage)` in orchestrator
- 13 core characters seeded mechanically from their existing systemPrompt prose
- Unit tests for the helper
- No changes to speaker-selection.ts or private-memory.ts
</objective>
